# Tests

`test_certificates.py` re-runs the scripts and logs in `certificates/` (via `make check`).

File-name prefixes in `certificates/`: `x1_` marks files written for this work (X1 is the project name; see the top-level README); `m5_` marks the brute-force end-to-end check of the network at h = 6 (`m5_xref_e2e.c`, the reproduction of the first referee's run); `m6_` marks the explicit-word search and verification for the F₁₆ transfer word (`m6_word_*`). The numbers are historical stage labels only.
